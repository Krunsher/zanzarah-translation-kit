# ZanZarah Translation Kit

This kit contains all the necessary tools to translate **ZanZarah: The Hidden Portal** to any language.

## 📋 Kit Contents

The kit includes the following files and folders:

```
ZanZarah_PTBR_Translation_Kit/
├── README.md                 # This file (documentation)
├── EXTRACT.bat               # Script to extract texts from .fbs files
├── COMPILE.bat               # Script to compile translation to .fbs files
├── tools/
│   ├── zzio_dbsqlite.exe    # Standalone tool to convert .fbs ↔ SQLite
│   ├── SQLite.Interop.dll   # Required DLL for SQLite
│   └── sni.dll              # Required DLL for .NET
├── scripts/
│   ├── extract_texts.py     # Python script to extract texts from database
│   └── inject_texts.py      # Python script to inject texts into database
└── base/                     # Folder for intermediate database (empty initially)
```

### Files Generated During Translation Process

The following files are **automatically generated** when you run the scripts (they are **not included** in the initial kit):

1. **`texts.json`** (in kit root)
   - Generated by: `EXTRACT.bat`
   - Purpose: Contains all game texts in JSON format
   - Action: Edit and translate this file

2. **`base/zanzarah.db`** (in `base/` folder)
   - Generated by: `EXTRACT.bat`
   - Purpose: Intermediate SQLite database (temporary file)
   - Action: No action needed (automatically used by scripts)

3. **`_fb0x02.fbs` and `_fb0x06.fbs`** (in kit root)
   - **Important**: You must first copy the **original** `.fbs` files from the game's `Data` folder to the kit root before running `EXTRACT.bat`
   - Generated by: `COMPILE.bat` (creates the **translated** versions)
   - Purpose: Translated game files ready to use
   - Action: **Copy these translated files back to the game's `Data` folder** to apply the translation

This kit allows you to translate the game to any language independently, without needing to install .NET SDK or clone the zzio repository.

### Prerequisites

- **Python 3** installed (available at https://www.python.org/)
- **Windows** (the `zzio_dbsqlite.exe` executable is for Windows)

### Quick Start Guide

#### Step 1: Extract Texts

1. **Copy the original `.fbs` files from the game to the kit folder:**
   - Go to the game's `Data` folder (e.g., `C:\Program Files (x86)\Steam\steamapps\common\ZanZarah\Data`)
   - Copy `_fb0x02.fbs` → paste into kit root folder
   - Copy `_fb0x06.fbs` → paste into kit root folder
   - **Note**: These original files will be used by `EXTRACT.bat` and later replaced by translated versions from `COMPILE.bat`

2. Run `EXTRACT.bat`:
   - It will convert the original `.fbs` files to SQLite
   - Extract texts to `texts.json`
   - Wait for extraction to complete

#### Step 2: Translate

1. Open `texts.json` in a text editor (recommended: VS Code, Notepad++)

2. Translate the texts while keeping:
   - ✅ JSON structure (keys, commas, etc.)
   - ✅ UIDs (e.g., `"802A94A1"`) - **DO NOT change**
   - ✅ Formatting tags like `{4*Name}`, `{5*Title}` - **preserve exactly**

3. Example translation:
   ```json
   {
     "_fb0x02": {
       "802A94A1": "Tinezard",           ← Proper name, can keep or adapt
       "8053E1B1": "Critical hit - opponent does not perform critical hits"
     }
   }
   ```

4. Save the file

#### Step 3: Compile

1. Run `COMPILE.bat`:
   - It will inject translated texts into the database
   - Compile the final `.fbs` files

2. The translated `.fbs` files will be in the kit root:
   - `_fb0x02.fbs` (Interface/Items)
   - `_fb0x06.fbs` (Dialogs)

3. **Apply the translation to the game:**
   - Go to the game's `Data` folder (e.g., `C:\Program Files (x86)\Steam\steamapps\common\ZanZarah\Data`)
   - **Backup** the original files first (rename to `.bak`)
   - Copy the translated `_fb0x02.fbs` and `_fb0x06.fbs` from the kit root to the `Data` folder
   - Start the game and enjoy the translation!

### File Structure

- **`_fb0x02.fbs`**: Contains game interface texts, item names, spells, menus, etc.
- **`_fb0x06.fbs`**: Contains all character dialogs (NPCs).

**Important**: Only these two files contain translatable texts. Other `.fbs` files (`_fb0x00`, `_fb0x01`, `_fb0x03`, `_fb0x04`, `_fb0x05`) contain technical data and should not be modified.

### Formatting Tags

The game uses special tags for formatting. **Preserve them exactly**:

- `{4*Text}` - Color/name formatting
- `{5*Text}` - Title formatting
- `~~` - Line separator
- `{n*...}` - Other numeric formatting

Example:
```json
"8A42BCB1": "09{5*International Brand Manager}~~Rebecca Lester~~{5*Assistant Brand Manager}~~Sarah Nicholson"
```

### Troubleshooting

**Error: "Database not found"**
- Run `EXTRACT.bat` first to generate the database

**Error: "Python not found"**
- Install Python 3 from https://www.python.org/
- Make sure to check "Add Python to PATH" during installation

**Error executing zzio_dbsqlite.exe**
- Verify the file exists at `tools/zzio_dbsqlite.exe`
- Try running manually to see the error message

### Technical Notes

- The kit is **standalone**: no need for .NET SDK or zzio repository
- `zzio_dbsqlite.exe` is a self-contained executable
- The `zanzarah.db` database is automatically generated by `EXTRACT.bat`
- Python scripts use relative paths, working from any location
- The database is **overwritten** each time `EXTRACT.bat` runs (fresh start from original `.fbs`)
- The database is **updated** (not overwritten) when `COMPILE.bat` runs (only texts are changed)
